- [ ] Entity formed (LLC/Corp) — or file as individual inventor

- [ ] At least 1 figure attached (screenshot or diagram)
- [ ] Abstract under 150 words
- [ ] No trade secret values in claims (use "predetermined threshold" not exact numbers)
- [ ] Git commit date documented as conception evidence
- [ ] Prior art search run via AI (see `PRIOR_ART_RESEARCH_TARGETS.md`)
