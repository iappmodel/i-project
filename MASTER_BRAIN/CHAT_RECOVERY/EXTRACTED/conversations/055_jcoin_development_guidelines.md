```
Coin letter:  
J

Coin name:  
jCoin

Core meaning:  
Judgment

Human behavior it measures:  
jCoin measures **verified decision quality under meaningful context**.

It does **not** measure opinions, confidence, popularity, agreement, ideology, taste, or loudness. A user earns jCoins only when the system can verify that the user made a responsible, accurate, fair, useful, context-aware choice where the outcome can later be checked.

jCoin applies wherever the platform gives a user **choice + responsibility + consequence**:

- Moderation decisions
- Content reviews
- Marketplace reviews
- Campaign approvals
- Dispute decisions
- Safety escalations
- Creator quality evaluations
- Brand-campaign suitability checks
- Financial-choice prompts
- Community-governance votes
- Learning-path choices...
```
