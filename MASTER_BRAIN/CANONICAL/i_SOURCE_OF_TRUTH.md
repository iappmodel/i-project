## What Is [ i ]?

[i] is an Attention Wallet and Media Marketplace.

It transforms human attention into a measurable, rewardable, transferable asset.

Today:

Users create value.  
Platforms capture value.

[i] changes this.

Users receive compensation for verified attention.  
Creators receive compensation for verified engagement.  
Advertisers receive verified human consumption instead of estimated impressions.

The platform coordinates and verifies the exchange.

---

## The Core Problem

The internet runs on attention.

Attention powers: advertising, social media, entertainment, commerce, search, influence.

Yet the people providing attention receive almost none of the value created by it.

Current systems reward: clicks, views, impressions, follower counts.

These signals are weak. They are easy to manipulate. They do not measure genuine attention.

As a result: users are exploited, creators are underpaid, advertisers waste money, platforms become bloated middlemen.

---

## The Solution

[i] creates an Attention Economy.

Instead of: Advertiser → Platform

The flow becomes:

Advertiser → Creator → Viewer → Platform

Everyone participates. Everyone earns. Everyone benefits.

---

## The Three Participants

### User
Provides attention. Watches, engages, participates, completes actions, verifies presence. Receives rewards. Accumulates reputation. Builds an attention portfolio.

### Creator
Provides audience and content. Publishes, imports, runs campaigns, receives tips, earns revenue share. Earns based on quality, engagement, trust, attention delivered — not follower count.

### Advertiser
Purchases verified attention. Launches campaigns, defines actions/rewards/verification requirements, tracks outcomes. Receives higher quality attention, less fraud, better conversion, transparent reporting.

---

## The Core Loop

```
Watch → Verify → Reward → Wallet → Spend / Convert / Withdraw → Repeat
```

This is the heartbeat of [ i ]. If this loop is broken, the platform is broken.

---

## Attention Verification

Goal: qualification, not surveillance.

Verification may use: dwell time, interaction quality, navigation behavior, completion rates, device signals, eye tracking (optional), behavioral patterns.

Attention quality matters. Not raw views.

---

## The Wallet

Center of the platform. Stores balances, rewards, pending earnings, restricted earnings, transaction history, reputation-linked privileges. The user's economic identity.

---

## Initial MVP Currencies

| Currency | Role |
|----------|------|
| **aCoins** | Attention currency — verified attention activity — foundation currency |
| **iCoins** | Cash-value currency — withdrawable, spendable, tradable inside ecosystem |
| **vCoins** | Utility currency — boosts, features, tools, internal actions — not cash substitute |
| **eCoins** | Engagement currency — meaningful participation |
| **oCoins** | Origin currency — imported value and external platform provenance |

## Trust System

Trust is a primary asset. Difficult to gain, easy to lose.

Trust determines: payout speed, earning limits, conversion rates, feature access, reputation.

---

## Revenue Model

Baseline target: **60% Creator · 30% Viewer Reward Pool · 10% Platform**

The platform wins when creators and users win.
