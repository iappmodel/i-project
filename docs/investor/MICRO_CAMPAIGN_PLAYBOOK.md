# Micro-campaign playbook ($500–$2k)

Use when you need **B2 commercial proof** without a full LOI.

## Structure

| Step | Action |
|------|--------|
| 1 | Pick one sponsor clip (15–60s) with clear CTA |
| 2 | Set reward band: $0.50–$2.00 equivalent in i per completed verified view |
| 3 | Cap sessions: 200–500 (controls spend) |
| 4 | Run on `dev_stack.sh` or cloud pilot with real POP holds |
| 5 | Export: sessions started, completed, rejected, avg attention score, total payout |

## Budget example ($1,000)

- 400 sessions × $2.00 max earn = $800 viewer pool (30% of 60/30/10 narrative)
- $100 platform · $100 creator reserve (adjust per deal)
