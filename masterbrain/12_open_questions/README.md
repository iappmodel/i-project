# Open questions

A **parking lot** for unresolved items extracted during chat ingestion — not a duplicate of the ledger.

## How to use

1. When importing a chat via [ingestion-template.md](../01_chat_inventory/ingestion-template.md), copy unresolved **Open Questions** here as dated bullets.
2. Link each question to ledger row(s) and repo paths.
3. Close questions inline when decided; do not delete history — strike through or move to a `resolved/` note later.
