02 · Core · Earn Affordance

REWARD

The primary earn mechanism — a glass pill showing coin offers, engagement arcs, and verified settlement. The moment attention becomes money.

When sponsored or reward-bearing media plays, the REWARD pill surfaces the exact coin amount before the user commits. No hidden thresholds. The arc fills only with genuine dwell and attention score alignment. On completion, a 5-gate server-side engine (POPS) decides full or nothing — never partial. Settlement runs via Edge Functions, not client-side.

Investor Pros
  • Prices attention at point of consumption — familiar UX, novel economics
  • Transparent pre-commit offer reduces fraud disputes
  • Server-verified payout (POPS + Edge Functions) — no client-side inflation
  • 30% of sponsored revenue funds viewer rewards — aligned incentives
  • Non-intrusive glass overlay preserves immersion completely
  • Maps directly to Loop 1: Watch → Verify → Reward → Wallet

03 · Infrastructure · Trust Layer

POP

Proof-of-Presence — the 5-gate verification engine that makes [ i ]'s attention economy credible. On-device gaze, server-side settlement, zero-knowledge privacy.

POP v2 is shipped. Gaze data stays on the device — only a pass/fail score travels to the server. Five sequential gates (device signal, dwell, attention score, completion, fraud check) must clear before Edge Functions mint any coin. Bots cost more than they earn. Trust tiers unlock higher conversion rates over time, rewarding genuine users.

Investor Pros
  • Advertisers get certified attention — not estimated impressions
  • Privacy-first: raw gaze never transmitted, only pass/fail signal
  • iOS ARKit + Android MediaPipe — native on-device vision
  • Fraud economics inverted: gaming costs more than honest participation
  • Trust tiers create durable retention — users level up to unlock exits
  • Durable settlement: pending-first prevents instant-drain exploits

04 · Economic · Value Center

WALLET

The Attention Wallet — dual ledger, pending → available settlement, convert/withdraw/tip/spend. Where verified seconds become spendable money.

Tab 4 of the 5-tab dock. iCoins carry cash value; vCoins are platform-spend tokens. Balances move from pending to available per trust tier. Three exit paths: convert (tier-multiplied), withdraw (bank/card/crypto), or spend (NFC/QR/tip). Every fee is declared upfront. No hidden deductions.

Investor Pros
  • Dual ledger prevents inflation — separate earning and spending currencies
  • Pending-first settlement blocks instant-drain exploits
  • Trust tier gates monetize long-term engagement over quick churn
  • Multiple exit paths (bank, card, crypto, in-app) increase utility
  • Transparent fee structure builds trust — no surprise deductions
  • 60/30/10 revenue split: creator / viewer / platform — aligned

07 · Social · Engagement Layer

GESTURE RAIL

Configurable multi-tap system: Like (tap), Save (double-tap), Boost (triple-tap), Creator Offer (hold). One button, four actions. No wallet debit on social gestures.

The right-side action rail uses 40px glass circles. Each button maps to a gesture engine: single tap toggles like; double-tap saves to Loop 2 vault; triple-tap fires boost; long-press opens creator tip/offer flow. The order is user-configurable via Controls. No wallet friction on basic social interactions — only Hold Love involves pending settlement.

Investor Pros

  • Familiar TikTok interaction model — zero learning curve
  • Configurable: users customize their rail per Controls
  • Boost creates demand-side vCoin spend — user-driven promotion
  • Hold Love opens direct creator economy — tips, offers, subscriptions

08 · Shell · Session Progress

TIMER LINE

2px full-width progress indicator — playback on organic, earn window on sponsored. The subtle signal that time is becoming value.

A minimalist 2-pixel line spans the top of the immersive shell. On organic content: playback progress. On sponsored: the earn window fills with green/mint as verified attention seconds accumulate. Skip or look away — the fill pauses. This is the lightest possible affordance to communicate "your time is being valued" without breaking immersion.

Investor Pros
  • Minimal footprint — 2px, never disrupts content consumption
  • Dual-mode intelligence — organic vs. sponsored behavior
  • Instant user comprehension — familiar progress bar metaphor
  • Integrates with POP — pauses when attention score drops
  • Drives completion rates — visible progress motivates finishing

09 · Capstone · MVP Flow

LOOP 1

Watch → Verify → Reward → Wallet. The complete economic cycle. Every feature serves this one loop. The attention economy in four steps.

Loop 1 is the foundational MVP cycle. User watches content (Feed), presence is verified (POP gates), reward is earned (REWARD pill), and value settles in the Wallet. From there: spend, convert, or withdraw. Every other feature — Promo, ELO, gesture rail, timer — accelerates or supports this spine. If Loop 1 works, the economy works.

Investor Pros
  • Complete value cycle — not a promise, a working loop
  • Four steps from attention to money — minimal friction
  • Every feature maps to a loop step — clear product architecture
  • MVP-shippable — the loop works before platform scales
  • Expandable — Loops 2 and 3 add depth without breaking the spine
