Loop 1

The canonical MVP spine.

Concept

Loop 1 turns verified attention into held value — on top of full-bleed media, not in a separate fintech app. This is the story `app/` and `MVP_CANONICAL_FLOW.md` wire for investors.

Reference: `iapp_loop1_watch_verify_earn.html` · React immersive feed path.

Select offer

User taps sponsored content or Promo brief. Offer detail shows duration, gates, and split preview before watch starts — opt-in, not autoplay earn.

Watch

Immersive session with TIMER line, REWARD pill, and POP signals collecting. Skipping pauses earn timer. Consent/camera gate on production path.

Verify

Five gates + POP layers score session async. UI shows indicative attention score; authoritative payout follows server review — pending-first by design.

Reward

Qualified sessions credit pending — not instant wallet inflation. Edge Functions (`issue-reward`, `validate-attention`) govern mutations.

Wallet

Review passes → pending moves to available. Wallet chip increments; Loop 1 completes. User can convert, spend, or withdraw per trust tier.
