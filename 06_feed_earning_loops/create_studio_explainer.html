Create

Watch is demand. Create is supply.

Concept

The center + in the 5-tab dock is the Studio entry — elevated soft-UI button per Picture 2 design law. One tap from immersive feed to creator production surface.

Interaction

Tap the raised + button. The feed remains the home; Studio opens as the creator mode — not a separate app shell.

Transition

Feed dims and Studio slides up — preserving the phone-native feel. Creators never leave the [ i ] chrome.

Studio

Video editor with trim, text, captions, filters, timeline, and 9:16 export — aligned to `studio_video_editor.html` and preservation Studio modules.

Full Studio pipeline is partially built in integrations; MVP routes Create tab to presenter/studio paths.

Creator paths

Record new media, upload existing assets, or attach to a sponsor campaign — three entry points into the same proof-ready publish flow.

Proof-ready export

Export attaches StudioProof metadata — linking published media to the verification and reward layer. Sponsored content enters the feed with earn parameters already bound.

Platform impact

Create closes the two-sided marketplace: viewers earn attention on the feed; creators supply campaigns; the platform takes 10% while funding the viewer reward pool.

Pros
  • Native creator entry — no leaving the app.
  • Elevated + matches immersive design law.
  • Studio → Feed → Verify → Earn supply loop.
  • Proof metadata at publish (StudioProof roadmap).
  • ELO can assist creation (companion in Studio).
  • Same 9:16 format as immersive feed consumption.
  • Turns [ i ] from viewer-only into two-sided marketplace.

Create is the supply-side door: the + button opens Studio so every piece of content can enter the attention marketplace with proof, campaigns, and earn logic attached.
