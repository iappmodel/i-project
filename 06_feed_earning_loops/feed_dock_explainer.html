Feed

Immersive media home — Picture 2 law.

Concept

Feed is the default product entry: full-bleed vertical media with glass overlays — not a card-list dashboard or fintech wallet shell. Canon: IMMERSIVE_UI_DESIGN_LAW — TIMER line, REWARD pill, gesture rail, OUT-PROFILE, ELO center, 5-tab white dock.

MVP: ImmersiveFeedScreen default route (immersive-feed); watch sessions via beginImmersiveWatch path.

Default entry

App boot lands on Feed — same shell for organic clips and sponsor briefs. Promo, Wallet, and In-Profile are peer tabs; Loop 1 economics play out on top of media, not behind a separate “earn app.”

Vertical media

TikTok-style full-bleed stack: swipe up advances clips. No grey card chrome, no stories row as home. Media fills the phone; scrims keep text readable.

Gesture buttons

Right rail: Like/Love (gesture engine), Message, Share, Controls — 40px glass circles per gesture-buttons.css. Configurable order; cross-mode for offers. Not neumorphic 3D stacks.

ELO · center

Transparent membrane at screen center — voice-evoked companion, separate from OUT-PROFILE (creator identity bottom-left). Feed is secondary to the Human → Presence → Relationship stack.

Watch path

Timer line tracks session progress; REWARD pill shows offer amount. beginImmersiveWatch starts Loop 1 on the current clip — gaze/POP signals feed server-side validation without leaving immersive chrome.

POP verification

Proof-of-Presence gates (presence, dwell, gaze, completion) run through Edge Functions — rewards pending-first until review passes. No client-side currency writes.

Investor framing

Loop 1: Watch → Verify → Earn → Wallet. Feed is where the attention marketplace meets the user — verified eyeballs become iCoin, then spend/convert/withdraw from Wallet.
